How does a static website work?

Meet the files behind a simple website.

Sample article
This is sample content demonstrating the knowledge base. It is not a published work or professional experience attributed to Omid Kakaei.

Ready-made pages

A static website serves pages prepared as files. The browser reads HTML and uses CSS to display the layout.

Interaction in the browser

JavaScript can add features such as local search and content filters. These features do not necessarily need a database.

Where the boundary lies

Saving visitor messages or signing into an account requires a separate service. A contact page without such a service should not pretend to send messages.
