How to write a useful note

Turn a clear question into a note you can return to.

Sample article
This is sample content demonstrating the knowledge base. It is not a published work or professional experience attributed to Omid Kakaei.

Start with a question

A useful note starts with one specific question. Keep the scope small enough to explore in a few paragraphs.

Separate observation from interpretation

Record what you observed first. Then explain your interpretation and what still needs to be checked.

Make it easy to return

A clear title, a few keywords, and links to original sources make the note easier to find. End with an open question for further investigation.
