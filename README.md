# وب‌سایت امید کاکایی

وب‌سایتی ایستا، راست‌چین و بدون وابستگی خارجی یا فرایند build؛ آمادهٔ انتشار روی GitHub Pages.

## انتشار در GitHub Pages
1. یک repository بسازید و محتویات پوشهٔ `omid-kakaei-site/` را در ریشهٔ شاخهٔ `main` قرار دهید (از جمله `index.html` و پوشهٔ `assets/`).
2. در repository به `Settings`، سپس `Pages` بروید.
3. در بخش Build and deployment، گزینهٔ `Deploy from a branch`، شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب و ذخیره کنید.
4. پس از پایان انتشار، نشانی نمایش‌داده‌شده در همان بخش را باز کنید. پروژه‌های GitHub Pages ممکن است زیرمسیر repository داشته باشند؛ همهٔ پیوندهای سایت نسبی‌اند تا این حالت نیز کار کند.

## دامنهٔ اختصاصی (اختیاری)
دامنهٔ `omidkakaei.ir` در رزومه به‌عنوان وب‌سایت ذکر شده است؛ این بسته وضعیت مالکیت، DNS یا پیکربندی فعلی آن را تأیید نمی‌کند. برای اتصال، دامنه را در تنظیمات Pages ثبت کنید و رکوردهای DNS را مطابق راهنمای رسمی GitHub برای دامنهٔ خود تنظیم کنید. برای دامنهٔ اصلی معمولاً رکوردهای A/AAAA و برای زیردامنه معمولاً CNAME لازم است؛ مقادیر دقیق را از مستندات روز GitHub بگیرید. فایل CNAME عمداً اضافه نشده است. تا زمان تنظیم واقعی، canonical تعریف نشده است.

## افزودن مقاله
- فایل `_drafts/article-template.html` قالب خصوصی پیش‌نویس است. GitHub Pages مبتنی بر Jekyll محتوای پوشه‌های زیرخط‌دار مانند `_drafts` را منتشر نمی‌کند؛ فایل قالب را مستقیماً به ناوبری پیوند ندهید.
- برای انتشار، یک نسخه از قالب را در `knowledge/` یا `writing/` کپی کنید و نام فایل را مثلاً `strategy-note.html` بگذارید. متن‌های راهنما و عنوان، توضیح متا و پیوند بازگشت را بازبینی کنید. ارجاع‌های دارایی در قالب برای مقاله‌ای در یک پوشهٔ داخلی تنظیم شده‌اند.
- کارت/پیوند مقاله را به فهرست مناسب (`knowledge/index.html` یا `writing/index.html`) اضافه کنید. برای نمایش در صفحهٔ اصلی، پیوندی در بخش مناسب `index.html` اضافه کنید. نشانی مقاله را نسبت به همان فایل HTML بنویسید.
- عنوان‌های موضوعی فعلی در صفحات فقط موضوعات پیشنهادی‌اند، نه مقالات؛ پس از انتشار واقعی می‌توانید آن‌ها را تغییر دهید.

## ویرایش و پیش‌نمایش
- نام و عنوان حرفه‌ای: `index.html`.
- ایمیل: پیوندهای `mailto:` در فایل‌های HTML.
- رنگ‌ها و چیدمان: متغیرهای بالای `assets/styles.css`.
- برای پیش‌نمایش محلی، از ریشهٔ پوشه اجرا کنید: `python -m http.server 8000` و سپس `http://localhost:8000` را باز کنید.
- شمارهٔ تلفن عمداً در سایت نیامده تا اطلاعات تماس خصوصی منتشر نشود.

## ساختار
- `index.html`: معرفی، تجربه، پروژه‌ها، تحصیلات، مهارت‌ها و تماس
- `knowledge/index.html`: صفحهٔ حوزهٔ دانشی و وضعیت خالی
- `writing/index.html`: صفحهٔ نوشتارها و وضعیت خالی
- `_drafts/article-template.html`: قالب خصوصی پیش‌نویس
- `assets/`: سبک‌ها، اسکریپت کوچک ناوبری و نشان SVG
